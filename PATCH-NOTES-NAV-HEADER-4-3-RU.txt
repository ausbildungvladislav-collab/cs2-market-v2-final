CS2 MARKET — NAVIGATION + HEADER FIX 4.3

Исправления:
1. Кнопка «Ещё» теперь работает на компьютере и телефоне: открывает дополнительное меню, повторное нажатие закрывает его, клик вне меню и Escape также закрывают меню.
2. Переход по пунктам дополнительного меню закрывает меню и открывает соответствующую страницу.
3. Upgrader, Multiplayer, Баланс, Premium, Профиль и ADMIN доступны из дополнительного меню.
4. ADMIN остаётся защищённым серверной проверкой /api/admin/me. Кнопка появляется только при подтверждённом isAdmin=true. Проверка не отключена и не заменена локальным флагом.
5. Баланс вынесен из правой группы управления в отдельную позицию шапки между логотипом и переключателем валюты/профилем. На телефоне шапка перестраивается в компактную сетку.
6. Обновлены версии кэша: style.css?v=43 и app.js?v=41.

Почему ADMIN может не отображаться:
- Обычный браузер с file:/// не предоставляет Telegram Mini App initData; серверная авторизация администратора не выполняется.
- Открой опубликованное приложение через Telegram.
- В Render -> Environment проверь ADMIN_TELEGRAM_IDS: там должен быть числовой Telegram ID пользователя-администратора (не @username и не ID бота). Несколько ID указываются через запятую.
- После изменения переменной перезапусти/Deploy Web Service.
- В backend/server.js проверка requireAdmin продолжает блокировать неавторизованные действия.
