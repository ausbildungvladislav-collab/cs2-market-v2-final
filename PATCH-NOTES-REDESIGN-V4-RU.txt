CS2 MARKET — ПОЛНАЯ ПЕРЕСТРОЙКА ИНТЕРФЕЙСА V4

Изменения: переписана структура навигации: полноценный desktop sidebar слева и мобильный нижний dock с меню «Ещё». Главная страница перестроена в Player Hub: приветственный блок, показатели аккаунта, быстрые действия, подборка предметов и промо-разделы. Переработаны шапка, заголовки страниц, сетки и поведение интерфейса на узких экранах. На телефонах включены две колонки карточек, вертикальные рабочие формы, горизонтальная прокрутка таблиц и безопасные отступы Telegram/Android. Поля ввода, select, textarea и option принудительно получили контрастную тёмную тему, чтобы не было белых полей с белым текстом.

Функциональные ID и data-tab сохранены. Существующий app.js и backend-логика не переписывались. Добавлено меню mobileMoreMenu и mobileMoreToggle; существующий обработчик меню в app.js используется без замены бизнес-логики.

Изменены: index.html, style.css. Не изменялись: app.js, config.js, backend/server.js, render.yaml, assets, база данных.

Проверки: HTML ID duplicates, JavaScript syntax (node --check), CSS braces/structure, archive integrity. Реальный production запуск Telegram/Render не выполнялся в этой среде.
